Guide de configuration

1. Définissez le nombre de membres de votre équipe et cliquez sur "Créer l'équipe".

2. Remplissez le nom, le poste, le contrat (35h ou 30h) et les jours de repos de chaque personne. Les repos sont cochés individuellement — la semaine A/B pour le samedi se gère via la case "Sam A" et "Sam B" dans les jours.

3. Choisissez la semaine à planifier (A ou B est détecté automatiquement).

4. Cliquez → Aller au planning pour générer le tableau.

5. Utilisez ⚡ Auto-remplir pour une affectation automatique respectant toutes les contraintes, puis ajustez manuellement.
